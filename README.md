# ❤️ 我们的恋爱小站

一个纯静态的恋爱纪念网站：**恋爱计时 · 相册 · 点点滴滴时间线 · 恋爱清单 · 留言板 · 背景音乐**，部署在 GitHub Pages，联网即可访问。

## 在线访问

**https://shangjiel1.github.io/love-website/**

把网址发给对方，对方联网就能打开 💕

## 功能

- 🏠 **首页**：两人头像 + 恋爱计时（年/月/天/时/分/秒 实时跳动）
- 📷 **相册**：照片墙 + 点击放大浏览（支持左右切换、ESC 关闭）
- 💫 **点点滴滴**：时间线记录你们的故事
- ✅ **恋爱清单**：想一起完成的事，点击打勾（勾选状态保存在本地设备）
- 💬 **留言板**：云端同步（数据存在本仓库 `data/messages.json`，任何设备打开都能看到）
- 🎵 **背景音乐**：右下角音乐盒（首次点击页面任意处自动播放）
- 🔧 **管理后台**：`admin.html`（不改链接不外传）

## 怎么修改内容

1. **管理后台（推荐）**：打开 `admin.html`，按页面里的说明生成一把 GitHub 令牌（钥匙）粘贴保存，之后就能在网页里改名字/纪念日/文案、上传照片、管理留言。
2. **改代码**：编辑 `assets/js/data.js`（所有内容都在这一个文件里）后提交推送即可。

## 钥匙（令牌）说明

- 留言板写入、照片上传都需要 GitHub **Fine-grained token**，权限只给本仓库的 Contents 读写。
- 钥匙只保存在各人自己的浏览器 localStorage，**不会**出现在任何网页代码里。
- 你和对方各设置一次；没有钥匙的人只能看，不能写。

## 技术说明

- 纯 HTML/CSS/JS，无任何框架、无外部 CDN 依赖（国内访问友好）
- 背景音乐为程序合成的音乐盒旋律（`tools/gen_music.py`，纯 Python 标准库）
- 占位图片为程序生成的 SVG（`tools/gen_images.py`），上传真实照片后自动替换
