🔧 管理后台

改名字/纪念日/时间线/清单 · 上传照片 · 管理留言（改动会同步到云端，所有人生效）

🔑 第一步：GitHub 访问令牌（留言密钥）

网站的「留言板」和这里的所有修改，都要用一把钥匙写入云端（GitHub 仓库）。
这把钥匙只保存在你自己的浏览器里，不会出现在网页代码中。你和对方各设置一次即可。

📖 点开查看：如何生成钥匙（约 1 分钟）
  1. 浏览器打开 github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Token name 随便填（如 love-website），Expiration 选 90 天或 1 年
  3. Repository access 选 "Only select repositories"，勾选 love-website
  4. Permissions → Repository permissions → Contents 设为 Read and write（其余不动）
  5. 点 Generate token，复制生成的令牌（ghp_ 开头），粘贴到下面保存

✏️ 第二步：编辑站点内容

下面是整个网站的内容（JSON 格式）：名字、纪念日、首页文案、相册、时间线、清单都在这里。改完点保存即可全站生效。

📷 第三步：上传照片

选一张或多张照片上传，会自动放进相册并更新首页。

💬 留言管理

留言保存在仓库的 data/messages.json，所有设备自动同步。在这里可以查看或清空。
